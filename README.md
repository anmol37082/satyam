# SATYA Facility Services Pvt. Ltd. — Website

A premium, responsive Next.js frontend for SATYA Facility Services Pvt. Ltd.

## Included
- Home page with expanded brand story, service overview, differentiators, process, service area and enquiry CTAs
- About, Services, individual service detail pages, Gallery, Team and Contact pages
- Original 16 SATYA brochure images in `public/gallery/`
- Custom-generated wide team hero visual in `public/images/`
- Responsive mobile navigation and gallery lightbox
- Frontend-only contact form preview (no backend or database)

## Tech stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4 setup
- Lucide React icons

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```
